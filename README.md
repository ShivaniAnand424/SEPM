# Student Attendance Management System (SAMS)

## 📌 Project Overview
The **Student Attendance Management System (SAMS)** is a software engineering project designed to simplify and automate student attendance management. It helps manage student records, teacher details, attendance records, attendance percentage calculations, and attendance reports.

This repository contains the Software Requirements Specification (SRS), UML diagrams, practical assignments, white-box testing, and Gantt chart documentation related to the project.

## 🎯 Objectives
- Automate the student attendance recording process.
- Manage student, teacher, subject, and class details.
- Calculate attendance percentages accurately.
- Generate and maintain attendance reports.
- Prevent duplicate attendance entries.
- Provide role-based access for administrators, teachers, and students.

## ⚙️ Main Features
- User authentication and role-based access
- Student and teacher management
- Subject, class, and section management
- Attendance recording and modification
- Automatic attendance percentage calculation
- Attendance history and reports
- Low-attendance alerts
- Search and filtering of records

## 🛠️ Technologies and Requirements
The SRS identifies the following suitable technologies:

- **Frontend:** HTML, CSS, JavaScript, Bootstrap or equivalent
- **Backend:** Python, Java, PHP, Node.js, C# or equivalent
- **Database:** MySQL, PostgreSQL, Oracle Database, SQL Server or equivalent

*The final technologies depend on the implementation selected for the project.*
